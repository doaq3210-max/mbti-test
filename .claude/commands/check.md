모든 html파일의 제목, 깨진 링크, 콘솔 에러를 점검하고 결과를 통과 / 수정필요 표로 정리해서 보고할것.

점검 절차:
1. 프로젝트 내 모든 `.html` 파일을 찾는다.
2. 각 파일마다 다음을 확인한다.
   - **제목**: `<title>` 태그가 존재하고 내용이 비어있지 않은지 확인.
   - **깨진 링크**: `href`, `src`로 참조하는 내부 파일(HTML, CSS, JS, 이미지 등)이 실제로 존재하는지 확인. 외부 링크는 가능하면 접속 상태를 확인.
   - **콘솔 에러**: 브라우저(claude-in-chrome)로 각 페이지를 열어 콘솔 에러/경고가 있는지 확인.
3. 점검 결과를 아래 형식의 표로 정리해서 보고한다.

| 파일 | 제목 | 깨진 링크 | 콘솔 에러 | 상태 |
|---|---|---|---|---|
| (파일명) | (제목 내용 또는 없음) | (없음 / 목록) | (없음 / 에러 내용) | 통과 / 수정필요 |

- 하나라도 문제가 있으면 상태는 "수정필요"로 표시하고, 표 아래에 구체적인 수정 제안을 덧붙인다.
- 문제가 없으면 상태는 "통과"로 표시한다.
